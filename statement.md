# General Store Management System

## Problem Statement

Managing billing and sales records manually in a general store can be time-consuming and may lead to calculation errors. Small shop owners need a simple system to generate bills, maintain sales history, and track frequently sold products.

The purpose of this project is to develop a Python-based General Store Management System that automates basic billing operations and maintains purchase records in an organized manner.

## Scope

The scope of this project is to provide a basic computerized management system for small general stores. The system allows users to select products, generate bills automatically, and view previous sales information.

The project focuses on basic store operations and does not include advanced features such as database storage, online payments, inventory synchronization, or multiple user accounts.

## Target Users

The primary users of this system are:

- Small general store owners
- Shop employees handling billing
- Beginners learning programming through real-world applications

## High-Level Features

The system provides the following features:

- Product selection using product codes
- Automatic bill calculation
- Support for adding multiple products in a single bill
- Display of final bill amount
- Storage of sales history
- Viewing of product sales count
- Menu-driven user interface
- Input validation for user choices
